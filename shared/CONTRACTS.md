# Shared Contract Policy

The Python and TypeScript contracts in this directory are deliberately duplicated so each runtime has native types while the team still has an explicit review point.

**Rule:** any PR changing one contract file must update the other field-for-field.

Mapping conventions:

| Python | TypeScript |
|---|---|
| `UUID` | `string` |
| `datetime` | ISO-8601 `string` |
| `T | None` | `T | null` |
| `list[T]` | `T[]` |
| `dict[str, str | None]` | `Record<string, string | null>` |

The OpenAPI document generated by FastAPI at `/openapi.json` is the runtime API contract; Swagger at `/docs` is the human-readable API contract summary.
